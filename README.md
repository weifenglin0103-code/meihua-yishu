# 梅花易數排盤

純前端、無需建置。直接用瀏覽器開啟 `index.html` 即可使用（雙擊或放到任何靜態空間）。

## 設計系統與無障礙
- 色票、間距（4/8/12/16/24/32）、字級（13/14/16/20/28）定義在 `css/style.css` 檔頭的 `:root` 變數。
- 目標 WCAG 2.2 AA：文字對比 ≥ 4.5、控制項邊線 ≥ 3、觸控目標 ≥ 44px、吉凶一律「符號＋文字＋顏色」。
- 結果頁：上方「結論卡」（單一綜合吉凶、一句話、四條理由），下方「依據」預設折疊且記住展開狀態。
- 鍵盤：起卦方式頁籤支援方向鍵／Home／End；有「跳到主要內容」連結；切頁與起卦後焦點會移到標題。

## 手機 App（PWA）
這是 PWA：用手機瀏覽器開網址後可「加到主畫面」，之後像原生 App 一樣全螢幕開啟，**沒有網路也能排盤**
（程式與《周易》資料都已快取在手機上；只有雲端同步需要網路）。
- iPhone（Safari）：分享 → 加入主畫面
- Android（Chrome）：選單 → 安裝應用程式，或按頁面上方「安裝到手機」
- 注意：必須用 **https 網址**（或 localhost）才能安裝與離線；直接雙擊 `index.html`（file://）只能當一般網頁用。
- 更新程式後，請把 `sw.js` 裡的 `VERSION` 改成新值，手機才會清掉舊快取。

## 放到網路上
任何靜態空間都行（本 repo 根目錄的 `index.html`、`css/`、`js/`、`icons/`、`manifest.webmanifest`、`sw.js` 就是網站）：
1. **GitHub Pages**（已附工作流程 `.github/workflows/pages.yml`）：
   Settings → Pages → Build and deployment → Source 選「GitHub Actions」，之後每次推送到 `main`，網站就會自動測試並發佈。
   網址：`https://weifenglin0103-code.github.io/meihua-yishu/`
2. **Netlify / Cloudflare Pages / Vercel**：連到這個 repo，發佈目錄設 `.`（根目錄），不需建置指令。

## 功能
- 起卦六法：數字（三數）、時間（農曆年月日時）、字占（1–10 字依筆畫或古四聲，11 字以上依字數）、物數／聲音、隨機、手動指定
- 本卦、互卦、變卦；體用生剋；月令旺衰（旺相休囚死，月令可選「節氣」或「農曆月」）
- 《周易》卦辭、大象、動爻爻辭與小象；互卦、變卦卦辭；八卦類象；原書依據頁碼
- 每個區塊都能在「設定」頁勾選開關（記在瀏覽器）
- 分頁導覽：起卦、歷史紀錄、類象查詢、設定、帳號各自獨立一頁，導覽列固定在頂端，瀏覽器返回鍵可用；起卦頁的結果切走再回來仍在
- 類象查詢：《梅花易數》〈卦應〉八卦各二十多類詳細類象（p.183-198），可搜尋關鍵字，輔助判斷外應
- 十應：方應、日應（自動由日期算日干支）、刻應、外應、天時應、地理應、人事應，並做內外合斷
- 歷史紀錄：預設存在瀏覽器；設定 Supabase 後可用 Email 登入同步到雲端

## 已知限制
- 斷語分數是本程式的簡化規則（評分明細有列出），不是原書給分。
- 節氣月令用太陽黃經公式計算，誤差約 ±15 分鐘；交界前後 1.5 天內會提示。
- 時間一律以臺北時間（UTC+8）計；23 點起算子時，不換日。閏月沿用該月數字。
- 字占的筆畫與聲調是查表帶入，可能有錯（簡化字、異體字、多音字尤其），畫面上都可手動修改；一字占的左右拆分需自行數。
- 未收入論事十大應等篇章。
- 彖傳的標點依維基文庫；文字已抽查《周易正義》。卦辭、爻辭依傅佩榮書，三處錯字已依《周易正義》更正（見 `js/data-zhouyi.js` 檔頭）。
